#  NYC Yellow Taxi Trip Analysis – Power BI Dashboard

Interactive Power BI dashboard analyzing New York City Yellow Taxi trips.

## Project Overview
This project explores NYC Yellow Taxi data to uncover insights about:
- Trip volume and revenue trends
- Peak hours and busy locations
- Passenger count patterns
- Fare analysis (base fare, tips, total amount)
- Payment type distribution
- Trip distance vs duration

## Key Metrics (KPIs)
- Total Trips
- Total Revenue
- Average Fare
- Average Trip Distance
- Average Trip Duration
- Total Tips
- Average Tip %

## Visualizations
- Trip volume by hour / day
- Revenue by borough / zone
- Payment type breakdown
- Passenger count distribution
- Distance vs Fare scatter
- Top pickup / drop-off locations
- etc.

## Tools Used
- Power BI Desktop
- Power Query
- DAX

## How to Use
1. Download the `.pbix` file
2. Open with Power BI Desktop
3. Interact with slicers and visuals

## Dataset
NYC Yellow Taxi Trip Data (publicly available from NYC TLC)
